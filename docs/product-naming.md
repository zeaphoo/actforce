# 产品命名矩阵（记录）

产品线关系：**功能 × 规模** 二维，非上下级。

```
actforce（免费，入门）
   └─→ actforce-super（功能全开，单用户）      = "单人全功能版"
          └─→ actforce-mega（super 的多用户版） = "团队版（含 super 全部功能）"
```

| 版本 | 定位 | 一句话 |
|---|---|---|
| actforce | 免费入门 | 基础单用户 |
| actforce-super | 功能向（未来） | 单用户可用全部高级功能（能力深度） |
| actforce-mega | 规模向（原 actforce-pro，2026-08 改名） | super 的全部功能 + 多用户/团队协作 |

**对外话术（钉死关系，避免误解）**：
- "ActForce-Mega = ActForce-Super 的多用户/团队版"
- 不是 "Mega 比 Super 高的版本"——super 表达功能到顶，mega 表达规模放大

**升级路径**：
- 个人要更多功能：actforce → actforce-super
- 团队/公司要协作：actforce → actforce-super → actforce-mega（或直接用 mega）
